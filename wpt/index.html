assign-gingerly Test Suite

📋 About this test suite:

This directory contains Web Platform Tests (WPT) for the assign-gingerly library. All tests can be opened directly in your browser for debugging.

Browser Support Check:

⚠️ Important: These tests require a local web server to run properly. The test harness uses /resources/testharness.js which needs to be served via HTTP.

Quick start:
  • Python 3: python -m http.server 8000
  • Node.js: npx http-server
