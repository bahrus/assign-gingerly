Hydration benchmark

Two vanilla-JS pages show the same launches, with the same text. Both time from a script at the top of <head> to the end of their final script.

  • json.html: plain markup (no attributes), then the data again as <script type="application/json">, parsed with JSON.parse.
  • microdata.html: the same markup with itemprop attributes (plus <data value>, <time datetime>, <meta content>), read back into the same object from the DOM.

html is from the top script to the start of the final script: downloading and parsing the page (including, for json.html, the JSON text). script is the final script: JSON.parse, or reading the microdata. total is both. Rendering isn't included.

Run loads each page as a real, top-level page, alternating between them, then comes back here with the medians. (Frames aren't used: Chromium parses a page in a frame several times more slowly, which distorted an earlier version of this runner.) Regenerate the pages with node demos/hydration-benchmark/generate.mjs [sections].
